Voqal - AI-Powered Interview Practice App


Overview
Voqal is an innovative interview preparation platform that leverages AI to provide realistic interview practice sessions. Built with cutting-edge technologies, Voqal connects users with a conversational AI agent powered by Vapi.ai to simulate real interview scenarios, then delivers comprehensive feedback to help users improve their interview skills.

Key Features
� Realistic AI Interviews: Practice with a voice-based AI interviewer powered by Vapi's conversational AI technology

📊 Instant Feedback: Receive detailed analysis on your responses, pacing, and content after each interview

🔥 Performance Tracking: Monitor your progress over time with Firebase-powered analytics

📱 Modern UI: Clean, responsive interface built with Tailwind CSS

⚡ Fast Performance: Next.js optimized frontend for seamless user experience

Tech Stack
Frontend: Next.js 14 (App Router)

Styling: Tailwind CSS

Type Safety: TypeScript

Backend: Firebase (Authentication, Firestore, Cloud Functions)

AI Voice Agent: Vapi.ai integration

Deployment: Vercel
